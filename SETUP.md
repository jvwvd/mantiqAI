# MantiqAI Setup Guide

## Prerequisites

- Windows 11
- Node.js
- Docker Desktop
- Pi installed
- Git

## Project Setup

1. Clone the MantiqAI repository.
2. Open the project folder in VS Code.
3. Install the required project dependencies.
4. Make sure Docker Desktop is running.
5. Follow `AGENTS.md` for the general workflow.
6. Follow `CHALLENGE_ROUTER.md` for category-specific instructions.

## Configuration

Keep private credentials, personal configuration, session data, and local files outside the public repository.

Do not commit secrets or private configuration files.

Before publishing changes, review the files that will be uploaded and make sure they contain no private information.
